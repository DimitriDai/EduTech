# 下载系统使用规则

1. category 只能是：
   - vocab_note
   - practice_docx
   - audio
   - grading_results

2. filename 不手写，必须来自：
   GET /v1/files/out/{run_id}/{category}

3. 下载 URL 公式：
   /v1/files/out/{run_id}/{category}/{filename}

4. 禁止：
   - 用户输入 category
   - 用户输入 filename
