# 音频与播放协议锁定说明（v1）

> 本文档用于**锁定本项目中与词汇音频、URL、播放编排相关的核心协议**。  
> 其目的不是说明“怎么实现”，而是明确 **哪些规则一旦确定，未来不得随意修改**。

---

## 1. 适用范围

本锁定说明适用于以下模块及其衍生功能：

- 词汇音频离线生成（TTS / cache）
- global_cache.json / uploaded_vocab_cache.json
- Excel / JSON 导出（词汇表、练习表）
- 前端播放（乱序练习、跟读、听写等）
- 后续 Web / API / CDN 接入

凡涉及 **单词 → 音频 → 播放** 的功能，均必须遵守本协议。

---

## 2. Slug 协议（slug_v1）【强锁定】

### 2.1 定义

- 每个单词必须通过统一规则生成 `slug`
- slug 用于：
  - 音频文件命名
  - 音频 URL 路径的一部分
- slug 生成规则定义在：`utils/slug.py`
- 当前版本标识：`slug_v1`

### 2.2 锁定规则（重要）

- ❌ **禁止修改 slug_v1 的生成规则**
- ❌ **禁止“优化”“增强”“调整” slug 行为**
- ❌ **禁止对已有词重新计算 slug**

任何修改 slug 规则的行为，都会导致：
- 所有历史音频 URL 失效
- Excel / 前端 / 缓存全部断裂
- 必须重生成全部音频（成本极高）

> 若未来确有必要引入新规则，**只能新增 slug_v2，与 slug_v1 并行存在**，  
> 严禁覆盖或替换 slug_v1。

---

## 3. 音频 URL 协议【强锁定】

### 3.1 URL 结构

```

/static/audio/{accent}/{slug}.mp3

```

示例：

```

/static/audio/uk/resume.mp3
/static/audio/us/resume.mp3

```

其中：
- `accent` ∈ `{uk, us}`
- `slug` 来自 slug_v1
- 文件格式：`mp3`

### 3.2 稳定性要求

- 音频 URL **必须永久稳定**
- 相同单词 + 相同口音 → 永远指向同一 URL
- 允许 CDN / 浏览器 / 前端长期缓存

---

## 4. 音频字段协议（Entry 层）

### 4.1 标准字段

Entry（cache / schema）中允许并推荐存在以下字段：

- `audio_uk`：英式音频 URL
- `audio_us`：美式音频 URL
- `audio_primary`：**首选播放音频**
  - 当前规则：优先 UK，缺失则 US
  - 该字段由导出层 / resolver 决定

### 4.2 设计原则

- 音频字段只保存 **结果（URL）**
- 不在前端 / 导出层拼 URL
- 不在导出层生成音频

---

## 5. 播放编排字段协议（Computed Fields）【语义锁定】

### 5.1 combo

- 含义：**重复播放次数**
- 类型：`int`
- 示例：
  - `2` → 播放 2 次
  - `3` → 播放 3 次

> combo **不是字符串，不包含单词本身**  
> combo 只描述“播几遍”，不描述“怎么播”

---

### 5.2 timer

- 含义：**每次播放之间的间隔时间**
- 单位：毫秒（ms）
- 类型：`int`
- 示例：
  - `5000` → 每次播放间隔 5 秒

> timer 不包含任何展示符号（如 ⏱️）  
> timer 只用于播放控制

---

## 6. 职责边界（非常重要）

### 6.1 音频生成层

- 离线运行
- 幂等（可重复执行）
- 负责：
  - 生成 mp3
  - 写入 audio_uk / audio_us
- **不关心播放方式**

### 6.2 导出层（Excel / JSON）

- 只负责：
  - 读取 entry 中已有音频字段
  - 输出 audio_primary / combo / timer
- **禁止在导出层生成音频或拼接 URL**

### 6.3 前端播放层

- 只消费以下字段：
  - `audio_primary`
  - `combo`
  - `timer`
- 不推断、不补规则、不重算 slug

---

## 7. 缺失音频的处理约定

- 若 `audio_primary` 为空：
  - 前端应优雅降级（提示“暂无音频”）
  - 不允许报错或中断流程
- 缺失音频应通过离线工具补齐
  - 例如 repair / batch 工具

---

## 8. 总结（不可违反条款）

以下规则 **一旦违反，必然导致系统级破坏**：

- 修改 slug_v1 规则
- 改变 audio URL 结构
- 将 combo / timer 从数字改回字符串
- 在多个模块各自实现音频拼接逻辑

> 本协议的存在意义：  
> **保护已经生成的音频资产、历史导出文件、前端逻辑不被未来改动破坏。**

---

**协议版本：v1（已锁定）**  
**生效时间：首次全量音频生成完成后**
